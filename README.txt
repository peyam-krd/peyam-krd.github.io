PEYAM WEBSITE
Files: index.html (the site), cards.json (the list of cards), img/ (card pictures).

ADD A NEW CARD
1. Put two pictures in img/ : name-front.jpg and name-back.jpg (about 1400 px wide, JPG).
2. Open cards.json and copy one card block, paste it before the last ], add a comma after the block above, and change:
   id, nameKu, nameEn, captionKu, captionEn, front, back.
3. Save. Upload to GitHub. The site updates in 1-2 minutes.

REMOVE A CARD: delete its block in cards.json.
